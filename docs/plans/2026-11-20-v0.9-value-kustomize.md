# kwhy v0.9 (`kwhy value kustomize`, redesigned) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kwhy value kustomize <overlay> <kind>/<name> [<path>|--all]` names the kustomization entry, and the line when it can prove it, that sets a field of the built output (backlog V1, then P10 for `pod --kustomize`). The first attempt (shelved 2026-11-20, `docs/specs/01-value.md`) named wrong lines; this design trades override chains for a guarantee.

**Architecture:** `render/` gains an in-memory copy of the overlay stack and a build with one entry removed (krusty on `filesys.MakeFsInMemory`). `value/` gains `TraceOverlay`: one build plus one per entry, in parallel; fields compared by document identity and name-keyed paths; per field the innermost entry that moves it. Answers reuse `Answer`/`kwhy.value/v1`.

**Spec:** `docs/specs/01-value.md` (shelve notes), `docs/spikes/kustomize/README.md` (rules 1–5; rule 6, override chains, is dropped).

## Rules (what makes it safe)

1. **Identity:** documents are matched across builds by kind + `config.kubernetes.io/origin` (set with `buildMetadata: [originAnnotations]` on the copy's top kustomization) + position among those, never by final name.
2. **Name-keyed lists:** `containers[name=api]`, `env[name=PORT]`; index paths only for lists without names.
3. **Added by:** a document that disappears when an entry is removed was added by it; its fields come from its own file.
4. **Innermost entry:** a component and the patch inside it both move a field; the patch is the answer, the component the route.
5. **Line guard:** a file:line is named only when the located line contains the field's final value (scalars as rendered). Otherwise the answer names the entry (its line in its kustomization file, always true) and says the line couldn't be confirmed. Never a guessed line.
6. **No override chains** in v0.9: only the winner. A chain would need a build per step to be exact.
7. **Stops, never partial:** remote bases, `helmCharts:` and plugins stop with a message naming them; an entry whose removal fails the build is skipped for attribution and reported as such.

# kwhy backlog: what's missing after v0.5 (2026-11-20)

Rows marked **done** were built on 2026-11-20 (v0.6–v0.7, commit in the last column). What each command doesn't
cover yet, from the specs (`docs/specs/`), the plans' open decisions and `shortcut:`
comments, and what building v0.5 showed. Sizes: **S** under a day, **M** a few days, **L** a week or more
(spike first). Priority is how often a user hits it.

# kwhy v0.4 (`kwhy pod`, Krew) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kwhy pod <name>` shows, for a Pending pod, every failing scheduler check on every node, computed by the real kube-scheduler filter plugins, and kwhy installs as `kubectl kwhy` through Krew.

**Architecture:** `pod/` reads the cluster once (read-only), builds a scheduler `cache.Snapshot`, then runs each filter plugin in its own framework so a node reports every failing check, not only the first. A second, normal framework gives the scheduler's own first-failure view (used by the parity test). `cmd/kwhy` only wires flags. The algorithm is the validated spike in `docs/spikes/pod/main.go`; port its logic, don't import it.

**Tech Stack:** Go 1.27.1, `k8s.io/kubernetes` v1.37.2 (new, `pod/` only), `k8s.io/client-go` v0.37.2 (already direct), `github.com/spf13/cobra`, kind v0.33.0 (CI only), goreleaser `krews:` (CI only).

**Spec:** `docs/specs/03-pod.md` and `docs/specs/00-overview.md`. Read both.

## Global Constraints

- Read-only: only `get`/`list` against the cluster. Never create a pod, not even a dry run.
- `pod/` is the only package importing `k8s.io/kubernetes`.
- JSON carries `"schema": "kwhy.pod/v1"`.
- Never invent a reason: cells show the plugin's own reasons plus numbers read from the snapshot (requested/allocatable), nothing paraphrased.
- Follow the `go-guidelines` skill. Gate for every task: `gofmt -l .` prints nothing, `go vet ./...` and `go test -race ./...` pass.
- Commits: Conventional Commits, subject under 50 chars, only once the user approved executing this plan. Tags, releases and the krew-index PR need the user's go-ahead.

## Review Focus

1. **PreFilter attribution.** The spike restricts only `Filter` per framework, so every framework still runs every PreFilter plugin, and a PreFilter rejection of plugin A is reported under filter B. Each per-plugin framework must also restrict `PreFilter` to that plugin. Test in Task 3 (`TestEvaluatePreFilterOwnPlugin`).
2. **PreFilter `Skip`.** A plugin whose PreFilter returns `Skip` (pod has no affinity, no spread) must not run its Filter and must show `✓`, not an error. Test in Task 3.
3. **Pod already bound / Running.** `kwhy pod` on a scheduled pod says so (`Running on node-x`) and exits 0 without a matrix. Test in Task 4.
4. **Own pod in the snapshot.** The Pending pod is listed with all pods; it has no `nodeName`, so it must not count as allocated anywhere, and a workload's template pod must not be double-counted. Test in Task 2.
5. **Large clusters.** Listing 30,000 pods must page (`Limit`/`Continue`), and the matrix groups identical rows, so 1,000 nodes print a few lines. Test in Task 6 (benchmark) and Task 5 (grouping).
